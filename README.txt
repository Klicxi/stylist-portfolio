# Stylist Portfolio — первый макет

Это полностью локальный прототип без сторонних библиотек.

## Структура

- `index.html` — разметка страницы
- `styles.css` — дизайн и адаптивность
- `script.js` — мобильное меню, плавные переходы и появление блоков
- `assets/` — сюда позже положим настоящие фотографии

## Как запустить на Windows

1. Распакуйте архив.
2. Откройте папку проекта.
3. Дважды кликните `index.html`.
4. Сайт откроется в браузере.

Для редактирования лучше использовать Visual Studio Code.

## Где менять контент

В `index.html` ищите:
- `NAME.` — название/имя;
- `[Имя]` — имя стилиста;
- `BASED IN YOUR CITY` — город;
- тексты разделов;
- ссылки Telegram и Email;
- названия услуг.

## Как добавить реальные фотографии

Когда фотографии будут готовы, положите их в `assets/`, например:

`assets/hero.jpg`
`assets/look-01.jpg`
`assets/look-02.jpg`
`assets/look-03.jpg`
`assets/look-04.jpg`
`assets/stylist.jpg`

После этого заменим блоки `.image-placeholder` на обычные `<img>` с правильными `alt`.

Важный принцип: исходные фотографии лучше подготовить в хорошем качестве, а на сайт загружать оптимизированные JPG/WebP, чтобы мобильная версия не была тяжёлой.

## Следующий этап

Этот прототип специально сделан без привязки к конкретным фотографиям. После того как вы выберете визуальное направление, можно заменить заглушки на реальные фотографии и точно настроить:
- цвета;
- типографику;
- композицию;
- анимации;
- тексты;
- услуги;
- контакты;
- мобильную версию.
